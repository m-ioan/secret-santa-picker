# secret-santa-picker

A lightweight, responsive web application for organizing in-person Secret Santa gift exchanges.

🔗 **[Try It Live](https://m-ioan.github.io/secret-santa-picker/)**


## Features

-- Easily add, edit, or remove names while preventing duplicate entries, with everything saved automatically in localStorage.

-- Designed for single-device group gatherings. Each participant clicks the button next to their own name to reveal their assigned match and hides it before passing the device to the next person.

-- Guarantees no participant is ever matched with themselves
